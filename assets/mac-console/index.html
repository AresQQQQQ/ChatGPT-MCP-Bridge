FIRST-RUN SETUP

连接向导

在当前控制台完成 Tunnel 配置。配置仅保存在本机，不会同步到 GitHub。

1. 获取 Tunnel ID

在 OpenAI Platform 创建或打开一个隧道，确认已关联到实际使用的 ChatGPT 工作空间，再复制以 tunnel_ 开头的 tunnel_id。这个 ID 也需要在 ChatGPT 插件的 Tunnel 连接中选择。

打开 Tunnel 管理页面 ↗

2. 获取 Runtime API key

在同一 Platform 组织创建 Runtime API key，并确认具有 Tunnels Read + Use 权限。不要使用 Admin API key。

打开 Runtime API keys ↗

3. 在 ChatGPT 创建 MCP 插件（必需）

保存本机配置后，先关闭向导并启动 Bridge 与 Tunnel，再打开 ChatGPT Plugins，选择「+ → Add custom MCP server」。Connection 选 Tunnel，选择或粘贴上面的同一个 Tunnel ID，认证选项按当前 Bridge 配置处理（通常为无额外认证），确认风险提示后点击「Create as a plugin」。

注意：Runtime API key 只供本机 Tunnel Client 使用，不要粘贴到 ChatGPT 插件认证栏。Tunnel 就绪不代表 ChatGPT 插件已创建。

打开 ChatGPT Plugins ↗ · 查看官方步骤 ↗
