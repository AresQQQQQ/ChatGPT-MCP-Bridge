# Tree icon sources

These SVGs are the final tree-navigation icon sources used by the WPF console. Their path geometry is embedded in `src/ui/windows-console.ts`; keep the SVGs as the canonical upstream reference.

All three use the same UI color: `#60758F`.

- `project.svg` — Microsoft Fluent UI System Icons, **Text Bullet List Square 20 Regular**  
  `assets/Text Bullet List Square/SVG/ic_fluent_text_bullet_list_square_20_regular.svg`
- `module-long-term.svg` — Microsoft Fluent UI System Icons, **Cube Checkmark 20 Regular**  
  `assets/Cube Checkmark/SVG/ic_fluent_cube_checkmark_20_regular.svg`
- `module-temporary.svg` — Microsoft Fluent UI System Icons, **Cube Sync 20 Regular**  
  `assets/Cube Sync/SVG/ic_fluent_cube_sync_20_regular.svg`

Upstream repository: `microsoft/fluentui-system-icons` (MIT).
